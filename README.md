# cs-upsight

Release artifacts and documentation for Upsight, a customer success management desktop
app for Kong technical CSMs. The source, [`bashfulrobot/upsight`](https://github.com/bashfulrobot/upsight),
is private; this repo publishes what needs to be public.

- **Docs:** [upsight.bashfulrobot.com](https://upsight.bashfulrobot.com/)
- **Downloads:** [Releases](https://github.com/bashfulrobot/cs-upsight/releases/latest)
